## Contribution attribution

GitHub uses commit author dates for the profile contribution graph. The author email must be associated with your GitHub account, and commits must be reachable from the default branch of a standalone repository. For a private repository, enable private contributions on your profile if you want their counts displayed. Actual graph updates are controlled by GitHub.

## Updating

Run the importer again with the same handle and destination. Already imported submission IDs are skipped; existing history is not rewritten. New submissions are appended, and the index is refreshed. Commit any manual edits before rerunning.

## Time zones

Sidecar timestamps are UTC. By default the author timestamp uses your computer's local time-zone offset at the original submission instant. Use --utc for UTC author timestamps. Both choices preserve the original Unix timestamp; GitHub's displayed day can depend on the timestamp's time zone.
